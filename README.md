# くみたて あそび (kumitate-asobi)
参考書籍の「構成」の課題をもとに、画面で練習する遊び。見本を見て、形を選び、場所を決めて、自分で置く。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。
- v1：見本に重ねる（マッチング）。材料 ご石／色紙／プレート、部品 2/3/4/6、手助け 大/ふつう/小。
- v2：見本の横に作る（台紙に作る。合わない部品はその場に残る）。
- 次：顔・からだ（かお からだ あそびで実装）。
- 失敗の音・揺れなし（静かに戻る）。成功は「ことん」＋星。お祝いの強さは調整可。
- 記録・名前・声・顔は保存しない。カメラ・マイク不使用。設計: docs/spec.md
