# くみたて あそび 仕様（kumitate-asobi）（初版）

## 0. 設計思想（開発中の判断基準）
**パズルを完成させるゲームではなく、子どもが見本を見て、形を選び、位置を判断して、自分で構成するための教材にする。**
- 成功の基準は「見本と同じになったこと」。完成は結果であり、楽しさは、できたあとのごほうびとして使う。
- 迷ったら「子どもが見本を見る理由が残っているか」で決める。見本を見なくても当たる仕組み（手当たり次第に置けば入る、など）は、手助けを最大にしたときだけ許す。

## 3. 第1段階：見本に重ねる（7-1 (1)）
### 画面（子どもの画面は文字なし）
- 見本カード（左、縦長の画面では上）と、部品の置き場（右、または下）。
- 部品は、見本の一部と同じ形・同じ色・同じ大きさ。置き場では全体を同じ割合で小さく並べ、持ち上げると見本と同じ大きさになる（部品どうしの大きさの違いは、置き場でも残す）。
- 部品を見本の同じ場所の上で離すと、ことんと重なり、星が出て、音が上がる。ぜんぶ重なると、お祝い→少しして次の見本（同じ見本は続けない）。
- 違う場所の上で離すと、約0.35秒とどまって、静かに置き場へ戻る（音・揺れ・×は出さない）。
- 置いた部品は、つまみ直して外せる。部品は回さない（向きも見本どおりに選ぶ）。
- 同じ形・色・大きさの部品（車輪、同じ色のご石など）は、どちらの場所にも入る。

### 材料（支援者メニュー「材料」）
| 材料 | 見本 | 子どもが手がかりにするもの |
|---|---|---|
| ご石 | 丸い枠のカードに、色の丸 | 色（黒と白 → ＋赤 → ＋青） |
| 色紙 | 家・木・雪だるま・車・船・チューリップ・家と木・汽車 | 形・色・大きさ |
| プレート | 四角い枠を三角・四角に分けた線 | 形と向き（部品はみな同じ木の色） |

### 部品の数：2／3／4／6
- 色紙：2＝家・木／3＝雪だるま・車・船／4＝チューリップ・家（窓・ドア）／6＝家と木・汽車
- プレート：2＝対角線で2つの三角／3＝半分の四角＋2つの三角／4＝対角線2本で4つの三角／6＝上に四角2つ、下に三角4つ。左右・上下に返した形も出す（向きを見る）
- ご石：2〜6個。色の数は支援者が選ぶ（2／3／4色）

### 手助け（みんな共通）：入る範囲と、光の補助の両方を変える
- **大きい**：見本の上ならどこで離しても、合う空いた場所へ入る。空いた場所が、やわらかく光る（ヒント「出す」のとき）。5秒で、入る場所がさらに光る
- **ふつう**：合う場所の中心の近く（部品の短い辺の約35%以内）で離すと入る。10秒待つと、入る場所が光る
- **小さい**：場所をぴったり合わせる（短い辺の約18%以内）。光らない。ヒントは支援者が出したときだけ
- ヒント：出す／出さない。「ヒントを今出す」で、空いた場所と、合う部品の両方に、ゆっくり光る輪を出す

### 見た目
- 見本は、印刷のように平らに描く。部品は、影と少しの光沢で厚みを出す（重なったことが分かるように）。
- 色は、他のアプリと同じ、やわらかい手描き風の色。点滅なし。

## 4. 支援者メニュー（右上の点を1.2秒長押し）
- この場面：材料（ご石／色紙／プレート）、部品の数（2／3／4／6）、色の数（ご石のみ）、ヒント（出す／出さない）、ヒントを今出す、つぎの見本にする
- みんな共通：手助け（大きい／ふつう／小さい）
- くわしく：触れ方（最初の指だけ／どの指でも）、見た目（やさしい／ふつう／はっきり）、お祝いの強さ（なし／控えめ（初期値）／ふつう／派手）、音（なし／小／中／大）、説明をもう一度
- もとにもどす／とじる。「とめる」「おしまい」は、他のアプリと同じ位置

## 5. 約束（他のアプリと同じ）
- 子どもの名前・記録・声・顔・録音・写真は保存しない。カメラ・マイクは使わない。
- 子どもの画面に文字を出さない。支援者用の説明画面にだけ文字。
- 治療効果をうたわない。
- 画面の向きが変わっても、進行中の見本と置いた部品は残す。

## 6. 観察（案A）
- アプリには記録を残さない。支援者が紙に書く。
- 見るところ：置く前に見本を見ているか／形・色・大きさのどれで選んでいるか／入らなかったとき別の場所や部品を自分で試すか。

## 7. 第2段階以降の構想（未実装）
### 7-1 (2) 実物見本
- 見本カード（完成形）と、子ども用の空の台紙を並べる。台紙には線も色も出さない（見本を見て、場所を判断する）。
- 判定は「見本と同じ位置に、同じ部品があるか」。位置の許容は手助けで変える。
- 段階：見本を見せる／はじめだけ見せる（記憶を使うので難しい。最後の段階に置く）。
### 7-2 顔・身体
- 輪郭（顔／身体）の枠に部品（目・鼻・口・眉・耳／頭・胴・腕・脚）を置く。
- はじめは枠の中に薄い見本の図を出す（マッチング）→ 見本を消し、子どもが位置を考えて置く。
- 左右のある部品（目・耳・腕・脚）をどう扱うか（どちらにも入る／左右を区別する）を決める。

## 10. 第2段階：見本の横に作る（v2、2026-11-05 実装）
他のAI（Gemini・ChatGPT）のレビューで、次を確定した。
- 同じアプリの場面として切り替える（支援者メニュー「場面」：見本に重ねる／見本の横に作る）。
- 見本カードと、同じ大きさの何もない台紙を、すぐ隣に並べる（横長は左→右、縦長は上→下。画面の形で、カードが最も大きくなる並べ方を選ぶ）。
- 台紙で、見本と同じ位置（許す範囲：部品の短い辺の 大きい 60%／ふつう 35%／小さい 約18%）に離すと、ことんと入る。ただし範囲は、画面の短い辺の3%（指先ほど）より狭くしない（ご石・窓など小さい部品が、iPhone で厳しくなりすぎないため）。数字は実機で調整する。
- 合わない位置で離した部品は、**その場に残る**（音・示しなし）。子どもが自分でつまみ直せる。台紙の外で離すと置き場へ戻る。
- 台紙の手がかり：大きい＝置く場所のうすい点線の輪郭（台紙の上ならどこでも合う場所へ入る）／ふつう＝真ん中のうすい十字だけ／小さい＝なし。
- ヒント（出す）：待つと、ずれている部品と、その入る場所が光る（大きい5秒・ふつう10秒）。
- 同じ種類の部品は、空いている同じ種類の場所のうち、いちばん近い所に入る。入った場所は部品ごとに管理し、2つの部品が同じ場所を取り合わない。
- 見本は常に見せる。部品は回さない。材料は ご石・色紙・プレート。
- 次の版：見本を「はじめだけ見せる」（薄く残す）、ペグボード。
- 確認：Playwright（iPad縦横・iPhone縦横・SE）で、材料3×部品数4×手助け3。並べ方、残る／範囲の内外、置き場へ戻る、つまみ直し、完成→次の見本、回転後も残った位置、ヒント、メニューともとにもどす、第1段階の回帰、エラーなし。実機は未確認。
